# Boar.Red.Gateway.Defines

[![.NET](https://img.shields.io/badge/.NET-10.0-512BD4.svg)](https://dotnet.microsoft.com/)

Boar.Red 微服务框架（微服务架构），网关共享定义。包含网关服务端与客户端共享的常量与模型（HTTP 头键、服务信息、IP 封禁记录模型等）。

Boar.Red Service framework — shared definitions for the gateway. Contains constants and models shared between the gateway server and its clients (HTTP header keys, service info, IP block record models, etc.).

依赖 / Dependencies: `Boar.Red.Service`。

仓库文档见 [Boar.Red.Gateway](https://github.com/Boar-Red/Boar.Red.Gateway#readme)。

See the [Boar.Red.Gateway](https://github.com/Boar-Red/Boar.Red.Gateway#readme) repository for full documentation.
