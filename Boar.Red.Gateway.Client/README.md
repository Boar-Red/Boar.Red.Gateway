# Boar.Red.Gateway.Client

[![.NET](https://img.shields.io/badge/.NET-10.0-512BD4.svg)](https://dotnet.microsoft.com/)

Boar.Red 微服务框架（微服务架构），网关客户端封装。提供 `BrGatewayService`，供业务服务便捷调用网关相关接口（如 IP 封禁记录管理）。

Boar.Red Service framework — the gateway client wrapper. Provides `BrGatewayService` for conveniently calling gateway APIs (e.g. IP block record management) from business services.

依赖 / Dependencies: `Boar.Red.Service`、`Boar.Red.Gateway.Defines`。

仓库文档见 [Boar.Red.Gateway](https://github.com/Boar-Red/Boar.Red.Gateway#readme)。

See the [Boar.Red.Gateway](https://github.com/Boar-Red/Boar.Red.Gateway#readme) repository for full documentation.
